Agent runtimes

A runtime is the program that does the work, as opposed to the model that answers. It is separate from Current AI and from Agents because those two are about which model speaks and which persona it speaks as; this is about what is running. A row only reads Connected when a request to that runtime has just succeeded — nothing here is a stored label or an assumption.
